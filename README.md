# Gayathri PS — Portfolio

A responsive React + Vite portfolio website.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Extract this folder and open it in VS Code.
3. Open the VS Code terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
```

Vite creates the production site in the `dist` folder.

## Deploy

- **Vercel:** Import this GitHub repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
- **Netlify:** Import this GitHub repository. Build command: `npm run build`. Publish directory: `dist`.

## Personalize before publishing

- Replace the resume in `public/Gayathri-PS-Resume.pdf` if you update your resume.
- Add GitHub repository/demo URLs to each project card if you want visitors to open the source or live demo.
- Review the project descriptions and technologies for accuracy before publishing.
- The contact details and profile links are in `src/main.jsx`.
